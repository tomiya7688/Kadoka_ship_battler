# 船バトル設計

## 目的

Kadoka ship battler の船戦を、2D見下ろし・5対5・操作キャラ切替・Utility AI を前提に定義する。

参考にするのは『スライムもりもりドラゴンクエスト3 大海賊としっぽ団』の船バトルの骨格であり、数値やコンテンツをそのまま再現することは目的にしない。

## バトルの基本構造

1. 両船とも船体HPが残っている状態で砲撃戦を行う。
2. 船体HPが0になった船は「大破」状態になる。
3. どちらか一方でも大破すると、両船をつなぐ橋渡し部屋を通行可能にする。
4. 大破した船だけコアが攻撃可能になる。
5. コアHPが0になった船が敗北する。
6. 両船が大破した場合は、両方のコアが攻撃可能な状態で戦闘を続ける。

船体HPは勝敗条件ではなく、最終侵入フェーズを開くためのゲートとして扱う。

### バトル状態

船ごとに次の状態を持つ。

- `Intact`: 船体HP > 0。コアは保護される。
- `Breached`: 船体HP = 0。コアへの経路と攻撃判定を解放する。
- `CoreDestroyed`: コアHP = 0。敗北。

戦闘全体の橋状態は次で決める。

`bridgeOpen = playerShip.Breached || enemyShip.Breached`

橋が開いても、`Intact` 側のコアは攻撃できない。

## 敵船への侵入

### 船体HPが残っている間

通常の橋移動では侵入できない。

侵入手段は以下に限定する。

- キャラクター自身を大砲から発射する。
- キャラクター固有能力による侵入。
- 将来追加する特殊弾・特殊設備による侵入。

### どちらかの船が大破した後

橋渡し部屋が両方向に開く。歩いて相手船へ移動できる。

大破した側が一方的に攻め込まれるだけではなく、守る側も橋を使って反撃・妨害に出られる。

## 砲台

スラもり3を参考に、標準船は2種類の砲台を持つ設計とする。

- `DirectCannon`: 低い弾道。直線的で到達が速い。
- `ArcCannon`: 高い弾道。Directとは異なる飛行経路を取る。

砲台のワールド上の基準位置は全船種で共通とする。船種によって変わるのは部屋構造と弾出現地点であり、砲台アンカーと侵入口アンカーは共通である。

現在の1砲台プロトタイプは、2砲台対応の基盤へ段階的に置き換える。

### 2Dでの弾道表現

見た目は2D見下ろしだが、弾道には論理的な高さを持たせる。

```text
ProjectileFlight
├─ trajectory: Direct / Arc / Special
├─ progress: 0..1
├─ logicalHeight
├─ speed
├─ hardness
└─ collisionProfile
```

弾同士が衝突できるかは、画面上の座標だけではなく論理的な高さも含めて判定する。

これにより「同じタイミングで撃っても弾道を変えてすり抜けさせる」という選択を作れる。

## 弾と弾デッキ

### デッキ

- 1陣営25枠。
- 同じ弾種を複数登録可能。
- 25枠は確率テーブルではなく、実際に循環する25個の個体。
- 待機中の個体からランダムに出現する。
- 場、船員の所持、砲台、飛行中にある個体は待機抽選から除外する。
- 着弾、撃墜、時間切れなどで消滅するとデッキへ返却する。

### 弾データ

最低限、次を持つ。

```text
AmmoDefinition
├─ id
├─ damage
├─ weight
├─ hardness
├─ flightSpeed
├─ allowedTrajectories
└─ projectileBehaviour
```

レア度は持たない。

### 硬さ

硬さは「弾同士の衝突時にどちらが残るか」を決める共通パラメータとする。

ダメージ値とは独立させる。

具体的な硬さ同値時・硬さ差の処理式は、弾同士衝突の実装Issueで固定する。

## キャラクターを弾として撃つ

キャラクターも砲台へ装填可能なProjectileとして扱う。

```text
Crew
  -> CannonLoaded
  -> CharacterProjectile
  -> Flying
      -> ShotDown
      -> ReachEnemyShip
  -> Crew
```

キャラクター側には次を持たせる。

- `ProjectileHardness`
- 発射時速度補正
- 使用可能な砲台／弾道
- 飛行中の固有挙動
- 敵船到達時の着地点・侵入挙動

通常キャラは敵船到達後に船員状態へ復帰する。特殊キャラは飛行中の迎撃、軌道変更などを拡張できる。

## 船定義

船種ごとの差を1つの定義から参照できるようにする。

```text
ShipDefinition
├─ id
├─ roomMap
├─ ammoSpawnLayout
├─ baseHullHp
├─ coreRoomId
├─ directCannonAnchor
├─ arcCannonAnchor
├─ boardingAnchor
└─ presentation
```

### 船種ごとに変わるもの

- 部屋構造
- ドア構造
- 弾出現地点
- 基本船体HP
- 見た目

### 全船種で共通にするもの

- 砲台アンカーの意味
- 侵入口アンカーの意味
- コア破壊による勝敗ルール
- 25枠デッキ
- 5人編成

船パーツによるHP・攻撃・速度補正は、将来の拡張点として `ShipStatModifiers` を分離しておく。現段階では必須機能にしない。

## 部屋と移動

船内はRoom Graphで表現する。

```text
ShipMap
  Room
   ├─ Door -> Room
   ├─ Door -> Room
   └─ Anchor
```

経路探索はキャラ能力を受け取る。

- 通常
- 飛行可能
- すり抜け可能

飛行・すり抜けは「移動可能経路」を変える能力であり、視界そのものを壁越しにしない。

## 参考にしたスラもり3の要素

- 水平／上向きの2砲台。
- 弾同士をぶつける攻防。
- 船体HP0後に船同士をつなぐ経路が開き、内部のエンジン破壊が最終勝利条件。
- 仲間がAIで動き、キャラごとに異なる命令を選べる。
- キャラクター自身を砲台で撃ち出して侵入できる。
- 船の種類・パーツにより性能や見た目が変わる。

Kadoka側では5対5、操作切替、重量制運搬、前方扇状視界、学習するUtility AIを追加する。
